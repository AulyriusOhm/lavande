# Instructions projet — Lavande

## Todo : source de vérité sur Outline
- La todo du projet est le document Outline **« TODO — Lavande »** :
  https://docs.lanro.eu/doc/todo-lavande-FPRVroUFCF
  (collection « Programmation & projet », id `047010e6-0b49-4f0e-bca8-d1201b38bfe0`).
- `TODO.md` à la racine du repo n'est qu'un pointeur : ne pas y maintenir de liste de tâches.
- En début de tâche : lire le document Outline (MCP Outline, `mcp__outline__list_documents` ou
  `list_collection_documents`). Roman y ajoute des idées entre les sessions : l'état lu fait foi.
- Après livraison : mettre à jour le document Outline (`mcp__outline__update_document`,
  editMode « patch ») — statut ✓, commits, décisions actées. Les numéros `#n` du document font foi.
- Le document principal est une checklist cochable (« À faire » / « Fait », une ligne par action) ;
  les descriptions complètes, décisions et historique sont dans le document enfant
  « Détails & décisions — TODO Lavande » (https://docs.lanro.eu/doc/details-decisions-todo-lavande-z4sOuWhNzx).
